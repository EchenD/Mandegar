# Touch monitor motion story

Four chapters turn Mandegar's existing capabilities into a small interactive film: Idea, Space, Participation, Memory. The table buttons select and replay chapters. A shared blue signal changes from a spark into a spatial grid, an audience network, and a lasting imprint.

`storyboard-v1.png` was generated with the built-in imagegen tool as an art-direction reference. The monitor renders live canvas graphics and typography animated with GSAP; it does not show the reference sheet or static stage photographs. These are illustrative capability concepts, not records of delivered projects. No unverified years, client counts, event totals, or audience metrics are used.

The canvas uses the monitor's original aspect ratio, localized Persian/Arabic/English copy, reduced-motion support, interrupted-transition snapshots, and animation time that pauses while the page is hidden. Incoming and outgoing titles slide simultaneously; capability labels separate and dissolve; 48 shared signal points move continuously between rings, a spatial grid, an audience network, and a circular imprint. The chapter rail and number have their own staggered transitions.
